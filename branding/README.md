# Vitafolio – Marke

Alle Dateien sind SVG, Schrift ist in Pfade umgewandelt. Nicht von Hand bearbeiten.

## Dateien

- `logo.svg` – das Logo. Immer mit seiner Fläche, auf hellem wie dunklem Grund gleich. Nie umfärben, nie ohne Fläche verwenden.
- `wordmark.svg` (heller Grund) / `wordmark-dark.svg` (dunkler Grund) – Logo und Name in einem: das Logo-Zeichen ist der erste Buchstabe.

## Farben

| Rolle | Hell | Dunkel |
|---|---|---|
| Schrift | `#14213D` | `#F3EEE2` |
| Akzent (Gold) | `#A27420` | `#D9AE57` |
| Zeichen, zweite Fläche | `#B8872A` | `#D9AE57` |
| Logo-Fläche (Verlauf) | `#2B4170` → `#12203D` | gleich |

## Schrift

Outfit SemiBold – SIL Open Font License 1.1.

## Regeln

- Mindestgröße des Logos: 16 px.
- Freiraum um Logo und Wortmarke: mindestens ein Viertel der Logohöhe.
- Wortmarke auf hellem Grund: `wordmark.svg`, auf dunklem Grund: `wordmark-dark.svg`.
