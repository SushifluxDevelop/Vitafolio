## English

Vitafolio is a free, open-source app for writing job applications that look good: a CV built from simple blocks, a cover
letter, an optional cover page and attachments – in classic or modern designs, exported as PDF or Word. An application
tracker keeps an eye on what was sent where. AI help is optional: with your own API key, with a local model, or by
copying a ready-made prompt into the AI subscription you already have.

**Status:** in development – there is no release yet.

**Platforms:** a Windows program and a Docker image (Unraid, NAS, Linux servers) with a web interface and login.

## Deutsch

Vitafolio ist eine kostenlose Open-Source-App für Bewerbungen, die gut aussehen: ein Lebenslauf aus einfachen
Bausteinen, ein Anschreiben, auf Wunsch ein Deckblatt und Anlagen – in klassischen oder modernen Designs, als PDF oder
Word. Ein Bewerbungs-Tracker behält im Blick, was wohin verschickt wurde. KI-Hilfe ist freiwillig: mit eigenem
API-Key, mit einem lokalen Modell oder indem man einen fertigen Prompt in das KI-Abo kopiert, das man schon hat.

**Stand:** in Entwicklung – es gibt noch keine Veröffentlichung.

**Plattformen:** ein Windows-Programm und ein Docker-Image (Unraid, NAS, Linux-Server) mit Weboberfläche und Login.
